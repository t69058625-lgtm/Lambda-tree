# Project Passport: Lambda-tree Engineering Specs

## System Architecture Matrix
- **Core Technology Components**: Python 3.11 Platform Environment, Pygame 2 Graphical Suite, SDL2 low-level hardware abstraction runtime layer.
- **Interface Methodology**: Modular, stacking layout block paradigm modeled after Qt's automated resizing containers (`VBoxLayout`).
- **Target Environments**: Native Windows Workstations (via MSYS2 UCRT64 Console Environment Pipeline) & Portable Android ARM environments running Termux app ecosystems.

## Repository Distribution Core Mapping
- `main.py`: Central Application Orchestrator. Directs game state machines, window window resize events, active inputs multiplexing, and core LERP update triggers.
- `window.py`: Geometric Widget Architecture Layouts. Houses `Canvas` classes, AST nodes layout calculators, Qt-mode stacking layouts (`VBoxLayout`), and custom engine visualization block painters.
- `expr.py`: AST Mathematical Semantics Compiler. Solves binding abstractions, executes automated safe alpha-conversion variable renaming, parses tokens, and traces reduction paths.
- `layout.py`: Positional Graph Distribution. Maps nodes evenly using bounding limits across screen coordinates.
- `render.py`: Low-level Pygame canvas primitive draw operations.
